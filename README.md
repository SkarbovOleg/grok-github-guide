# Как Grok работает с GitHub

Интерактивная презентация-сайт, которая объясняет, как Grok (xAI) интегрируется с GitHub.

## Что внутри

- Как подключить GitHub к Grok
- Какие действия доступны (создание репозиториев, загрузка кода, ветки, PR)
- Как выглядит типичный сценарий работы
- Безопасность и контроль доступа

## Открыть презентацию

Просто открой [index.html](index.html) или перейди на GitHub Pages (если включены).

Управление:
- Кнопки «Назад / Далее»
- Стрелки клавиатуры ← →
- Пробел — следующий слайд
- Свайп на мобильных

## Репозиторий создан Grok

Этот репозиторий и сама презентация были созданы и залиты Grok напрямую через GitHub API.
