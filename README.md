# Grok × GitHub — Презентации

Интерактивный сайт с **5 презентациями** о том, как Grok работает с GitHub.

## Презентации

1. **Как Grok работает с GitHub** — обзор интеграции и типичный сценарий
2. **Создание репозиториев и загрузка кода** — от пустого репо до первого коммита
3. **Ветки, Pull Requests и Issues** — полноценный workflow
4. **Чтение, поиск и анализ кода** — как Grok видит твои репозитории
5. **Безопасность и лучшие практики** — права доступа и контроль

## Как открыть

- Открой `index.html` в браузере
- Или включи GitHub Pages: Settings → Pages → Branch `main` → Save

После включения Pages: **https://skarbovoleg.github.io/grok-github-guide/**

## Управление

- Меню — выбор презентации
- Стрелки ← → / пробел — навигация по слайдам
- Escape — вернуться в меню
- Свайп на мобильных

---

Репозиторий и сайт созданы Grok через GitHub API.
